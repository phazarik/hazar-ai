Hello! Here is the control panel overview:

  • Model: Selects the intelligence tier. Auto (default) dynamically routes to Fast or Smart based on prompt complexity.
  • Skill: Injects specific system instructions into the LLM context. I am using prompt-master by default.
  • Max Tokens: Caps the length of the generated response. 900 is a reasonable number. Uncheck to remove the limit entirely.
  • Status: Outputs the current size of the memory database to the log window.
  • Optimize: Strips whitespace and empty lines from attached files to save context space.
  • Memory: Retains conversation history.
  • Claer Memory: Wipes all conversation history.
