Help

Here is some important things to tweak:

  • Model: "Automatic" picks a model based on the question. "Quick" suits everyday questions. "Detailed" suits harder tasks. "Local" lists supported models in models/. One model loads at a time. Local inference has no provider quota, but the context window remains finite.
  • Local LLMs: Place complete GGUF files or supported Transformers model folders in models/ directory. Select "Local", then choose a model from the dropdown. Only one model loads at a time to conserve memory.
  • Skill: Adds instructions for a particular task. Use the dropdown menu to pick instructions sets. Make sure that tey are kept in the format ~/.claude/skills/skill-name/SKILL.md
  • Optimize: Click to turn file optimization on or off. When on, repeated file content is sent once, and unnecessary spacing in valid JSON is removed. Code and comments stay intact. This can reduce the amount of text sent to the model.
  • Memory: Click to turn memory on or off. When on, the app uses saved conversation history and saves new messages. Older messages may be shortened into summaries, so some details can be lost. When off, the next request does not use or save conversation memory. Switching it off does not delete existing memory.
  • Max Tokens: Sets the maximum reply length. A larger number allows a longer reply; a smaller number may cut it short. Uncheck to use the model's default limit.
  • Clear Chat: Removes messages from the screen without deleting saved memory. Saved messages may return after refreshing the page.
  • Clear Memory: Deletes saved conversation history. Use Clear Chat to hide messages without deleting that history.
